## 一、必须先解决：原代码的引脚冲突

**Arduino 上 `A3` 与数字口 `3` 是同一个引脚（PC3）。**

原 `2.ino` 里：

```cpp
pinMode(3,  INPUT);        // 第 668 行：把中循迹探头设为输入
...
pinMode(A3, INPUT_PULLUP); // 第 685 行：把同一个引脚改成编码器上拉输入
```

后者覆盖前者 → **中探头从未被正确配置**，`b = digitalRead(3)` 读到的是被上拉的编码器信号，中探头一直是坏的。

本程序把中探头移到 **D4**，彻底避开冲突。若你的实车已经按旧接线焊接，**必须改线**，否则中循迹通道无效。

## 二、硬件接口假设

| 功能 | 引脚 | 模式 | 说明 |
|---|---|---|---|
| 左循迹探头 | A4 | INPUT | 数字输出，见黑为高（若反相需改代码极性） |
| **中循迹探头** | **D4** | INPUT | **原D3，因与 A3 冲突改 D4** |
| 右循迹探头 | A5 | INPUT | 同上 |
| 左编码器 | A3 | INPUT_PULLUP | PCINT11/PC3，单路信号 |
| 右编码器 | A2 | INPUT_PULLUP | PCINT10/PC2，单路信号 |
| 左轮驱动 | D6 正 / D5 反 | OUTPUT PWM | Motor-1，Timer0 |
| 右轮驱动 | D10 正 / D9 反 | OUTPUT PWM | Motor-0，Timer1 |
| 超声波 | D14 TRIG / D15 ECHO | OUTPUT / INPUT | HC-SR04 类 |

**PCINT 选择性使能**：A2/A3/A4/A5 同属 PINC、共用 `PCINT1_vect`。代码用位掩码只放行编码器：

```cpp
PCMSK1 |= _BV(PCINT10) | _BV(PCINT11);   // 只开 A2/A3，挡掉 A4/A5 循迹
```

**电机接法**：带符号 PWM 的标准 H 桥，任一时刻只有一个方向脚有 PWM；两脚都为 0 = 松手（非刹车）。`motorLR()` 是全工程唯一写电机引脚处。

**★ 左右映射反直觉**：左轮 = Motor-1(D6/D5)，右轮 = Motor-0(D10/D9)。这是由「原地左转 = 左轮倒转」反推的，引脚编号与物理左右**没有对应关系**，改接线必须同步改 `motorLR()` 里这四个数字。

## 三、控制结构（三层闭环）

```
外环  循迹环  三探头横向误差 → 差速速度        （修正真实路径偏移）
中环  航向环  差速积分航向角 → PI → 差速速度  （消除持续跑偏）
内环  速度环  左右轮独立 PI → PWM             （抗电压波动/电机差异）
              ↓ 叠加
        delta = lineCmd + headCmd + trimBias
        tgtL = base - delta/2   tgtR = base + delta/2
```

| 环路 | 输入 | 作用 | 无法解决 |
|---|---|---|---|
| 内环速度 PI | 编码器 | 电池电压跌落、电机性能差异、摩擦变化 | 轮径/齿比不同（会导致里程失真） |
| 中环航向 PI | 双轮里程差积分 | 持续性跑偏（电机不对称、车身偏斜） | 打滑导致的真实位置漂移 |
| 外环循迹 | 三探头 | 真实路径偏差、抗累积误差 | 无 —— 这是最终兜底 |

### 关键设计：测速用「周期法」而非「窗口计数法」

15 孔盘一圈仅 30 边沿（0.52cm/脉冲）。若用「50ms 窗口数脉冲」，30cm/s 时窗口内只有 3 个脉冲，量化误差 **±10cm/s**，经 kp=4 放大成 42 PWM 宽的扭矩台阶，车会持续在两档间跳。

改测相邻边沿间隔：`v = 0.5236cm / Δt`，`micros()` 精度 4µs → 分辨率 **±0.007cm/s**，提升约 750 倍。

停转处理取 `t = max(Δt, age)`：`age` 是距最后脉冲的时间，停转后随时间增长，速度按 1/t **连续衰减到 0**。若不取大者，测速会**冻结**在最后一个值 → 目标为 0 时误差恒为 −30 → PID 输出持续负 PWM → 车原地倒爬。

## 四、关键常量含义

### 机械标定（**必须按实车填写**）

| 常量 | 默认 | 含义 | 标定方法 |
|---|---|---|---|
| `ENC_PPR_L/R` | 30 | 每转边沿数 | 数码盘孔数 ×2；15孔=30。带减速箱的还要乘齿轮比 |
| `WHEEL_DIA_L/R_CM` | 5.00 | 有效直径 cm | 轮子量周长 ÷ π。左右不同则分别填 |
| `TRACK_WIDTH_CM` | 14.0 | 轮距 cm | 两轮接触点直线距离，影响航向角精度 |

**左右轮径/齿比不同的处理**：左右各用独立的 `CM_PER_EDGE_*` 常量。若左轮径 5.0、右轮径 4.8，只需把 `WHEEL_DIA_R_CM` 改成 4.8 —— 里程换算自动分别缩放，航向角计算随之正确。

### 时间与滤波

| 常量 | 默认 | 含义 | 调参方向 |
|---|---|---|---|
| `CTRL_PERIOD_MS` | 20 | 内环周期（50Hz） | 改小响应快但算力/抖动压力上升 |
| `SPEED_LP_A` | 0.50 | 测速低通系数 | 调大跟得快但抖（0.3~0.7） |
| `STALL_US` | 150000 | 停转判定 | 对应临界速度 3.49cm/s，低于此读 0 |

### 循迹环

| 常量 | 默认 | 含义 | 调参方向 |
|---|---|---|---|
| `SENSOR_GAP_CM` | 3.0 | 探头中心距 cm | 影响横偏量换算准确性 |
| `LINE_ERR_GAIN` | 0.45 | 横向误差→差速 | 转向不足就调大 |
| `OFF_LINE_CONF` | 3 | 连续命中几次才纠偏 | 防探头抖动引起蛇形 |

### 航向环

| 常量 | 默认 | 含义 | 调参方向 |
|---|---|---|---|
| `HEADING_KP` | 1.20 | 航向角→差速比例 | 跑偏拉不回来就调大 |
| `HEADING_KI` | 0.35 | 航向积分 | 消除持续跑偏靠它 |
| `HEADING_CLAMP` | 14.0 | 差速输出限幅 cm/s | 防止打滑时猛打方向 |
| `TRIM_MAX` | 6.0 | 静态补偿上限 cm/s | — |

## 五、标定流程（务必按序执行）

### Step 1 — 脉冲标定（决定一切的基础）

架空车轮，发 `R` 让它跑，读调试输出的 `spdL / spdR`：

```
实测/目标 = k  →  ENC_PPR = k × 当前值
```

例：设 30、实测 60 → 一圈实际 60 边沿 → `ENC_PPR = 60`。左右轮**分别测、分别填**。

### Step 2 — 轮距与轮径

- 轮径：量周长 ÷ π（左右各量）
- 轮距：两轮接触点直线距离

### Step 3 — 脉冲方向校验

前进时 `spdL / spdR` 必须为**正**、里程递增。若为负，说明编码器与电机转向相反，对调该轮电机两根线。

### Step 4 — 静态机械补偿 `trimBias`

车架空或短距离直线，**关掉循迹环**观察：若车稳定向右偏，说明右轮偏快/左轮偏慢 → 需减小右侧速度 → 发 `M-2`（负值 = 右轮减速）。

每次调整 1 cm/s，收敛即可。调好后这个值应接近 0 —— 因为速度环已经能自动匹配大部分差异。

### Step 5 — 速度环整定

顺序：**Kp → Ki**（本系统刻意不用 Kd）

```
S15    低速起步，先确认能动（不動则设 PWM_MIN=40~70 重新编译）
K2.0   起步偏软 → 逐步加到 K3.0 / K4.0
J5     稳态误差大（spd 长期 < tgt 且 pwm 未饱和）→ 加到 J10
```

判据：`spd` 能跟随 `tgt`，`pwm` 不长期饱和。

### Step 6 — 航向环整定

地面直线跑，看 `headDeg` 字段（航向角，度）：

```
跑偏时 headDeg 单调增长 → 先加 H（比例）
仍有稳态偏差（停不下来）→ 加 D（积分，从 0.35 起）
```

**注意**：`headDeg` 在转弯时必然变化，这是正常的——它只在直线段应趋于 0。

### Step 7 — 循迹环整定

压线测试，看 `lineErr` 字段（横向偏差 cm）：

```
横向有偏差但转向不足 → 加 LINE_ERR_GAIN（需改代码重编译）
蛇形振荡 → 加 OFF_LINE_CONF 或降 LINE_ERR_GAIN
```

## 六、串口指令

| 指令 | 作用 |
|---|---|
| `1,1` / `1,2` / `1,3` | 下发任务号 f，取件 + 出发 1.5s |
| `2,11` / `2,22` / `2,33` | 上报现场号 r，比对 f |
| `R` | 使能直线闭环 |
| `S` | 停止并复位积分 |
| `0` | 全复位（积分、补偿清零） |
| `V30` | 基速 cm/s |
| `K4` / `J10` | 速度环 Kp / Ki |
| `H1.2` / `D0.35` | 航向环 Kp / Ki |
| `M2` | 静态机械补偿（正=左轮加速） |

### 调试输出（100ms 一行，13 字段）

```
a,b,c,lineErr,headDeg,spdL,spdR,pwmL,pwmR,dist,f,r,stage
```

| 字段 | 含义 | 异常判读 |
|---|---|---|
| `a,b,c` | 三探头原始读数 | 全 0 = 丢线 |
| `lineErr` | 横向偏差 cm | 恒非 0 = 探头偏或未居中 |
| `headDeg` | 航向角（度） | 直线段单调增长 = 跑偏 |
| `spdL/R` | 实测速度 cm/s | 长期 0 而 pwm 有值 = 编码器故障 |
| `pwmL/R` | PWM 输出 | 长期 ±255 = 饱和，动力不足 |
| `dist` | 障碍距离 cm | 恒 999 = 无回波 |
| `stage` | 0等任务/1出发/2巡线/3等码 | — |

## 七、异常处理

| 异常 | 判据 | 动作 |
|---|---|---|
| 编码器停转 | `Δt ≥ STALL_US(150ms)` | 速度归零，PI 加大输出 |
| 测速撕裂 | 4字节变量被中断改写 | `noInterrupts()` 快照后计算 |
| 长阻塞 | `dt > 200ms` | 钳到 0.2s，防积分冲顶 |
| 积分饱和 | 输出长期顶限 | `integ` 钳 ±255 |
| 掉线 | 全白超 `LOST_LINE_MS(1.2s)` | 停车 + 关闭使能 |
| 探头抖动 | 单次横偏 | `OFF_LINE_CONF` 连续确认才生效 |
| 转向过猛 | 打滑 | `HEADING_CLAMP` 限幅 + 自动降基速 |
| 串口超长 | >15 字符 | 丢弃多余字符 |
| 非法指令 | 首字符不匹配 | 打印提示，不改状态 |

## 八、待实现的机构动作

```cpp
static void qu()  { }   // 取件
static void fan() { }   // 放置
static void gui() { }   // 归位
```

三个函数当前为空。实现时注意：
- **别写长 `delay()`** —— 会推迟后续的状态清理
- **别在内部改 `tgtL/tgtR` 或调 `motorLR()`** —— 会与速度环抢电机
- `fan()` 调用时车已被 `waitingR` 锁死，是安全的机构动作窗口
- 舵机需与电机**分电源、共地**，否则堵转电流导致复位
